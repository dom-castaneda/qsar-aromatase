## Context

- Dataset: 3,290 molecules with exact (`=`) pchembl_value (used for regression modelling)
- Split ratio: 80/20 (train/test)
- Two methods: (1) Random split, (2) Kennard-Stone
- Kennard-Stone = maximin distance algorithm that selects the training set to maximally span the chemical space, leaving the most "interior" points for testing
- KS will use ECFP4 fingerprints (filtered, 180 bits) for Euclidean distance computation
- No existing KS library installed — implement from scratch (standard algorithm)

## Implementation Steps

### Step 1: Create `scripts/07_data_split.py`

Single script that:
1. Loads `aromatase_bioactivity_clean.csv`, filters to exact measurements with pchembl
2. Loads filtered ECFP4 fingerprints and aligns by molecule_chembl_id
3. Performs **Random split** (80/20, stratified by activity class, random_state=42)
4. Performs **Kennard-Stone split** (80/20) using Euclidean distance on ECFP4 bits
5. Saves outputs to `data/splits/`:
   - `random_train.csv` — molecule_chembl_id + pchembl_value for train set
   - `random_test.csv` — molecule_chembl_id + pchembl_value for test set
   - `kennard_stone_train.csv` — same for KS train
   - `kennard_stone_test.csv` — same for KS test
6. Prints summary: sizes, pchembl distributions (mean/std/range per split), activity class balance

### Step 2: Kennard-Stone algorithm (native implementation)

```
1. Start: pick the two points with maximum distance → add to training set
2. Repeat until training set reaches target size:
   a. For each remaining candidate, compute distance to nearest point already in training
   b. Select the candidate with the maximum such distance
   c. Add it to training set
3. Remaining points = test set
```

This ensures the training set covers the extremes and spans the feature space uniformly.
