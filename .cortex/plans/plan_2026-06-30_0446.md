## Implementation: Single notebook `notebooks/colab_qsar_models.ipynb`

### Cell structure:

1. **Install & GPU check** — `pip install cuml-cu12 xgboost`, detect GPU, set `USE_GPU` flag
2. **Imports with fallback** — try cuML imports; on `ImportError`, fall back to sklearn for those 6 models
3. **Mount Drive / Upload data** — mount Google Drive or upload a ZIP of `data/` directory
4. **Data loading** — load `aromatase_bioactivity_clean.csv`, apply exact+pchembl filter, load all 12 filtered FPs
5. **Split loading** — load both `random_*` and `kennard_stone_*` split files, build X/y arrays for each
6. **Model builder function** — returns 16 models, using cuML/XGBoost-CUDA when GPU detected, sklearn otherwise
7. **Training loop** — nested loop: `for split in [random, KS]: for fp in 12_fingerprints: for model in 16_models:` → 10-fold CV + train + test eval
8. **Results CSV** — save `results_all_models.csv` (384 rows × columns: Model, Fingerprint, Split, R²_train, RMSE_train, MAE_train, R²_CV, RMSE_CV, MAE_CV, R²_test, RMSE_test, MAE_test, Time_s)
9. **Summary heatmaps** — test R² heatmap (model × fingerprint), best model per FP table
10. **Download results** — `files.download('results_all_models.csv')`

### GPU/CPU Fallback Logic (in notebook):

```python
try:
    import cuml
    from cuml.linear_model import Ridge, Lasso, ElasticNet
    from cuml.neighbors import KNeighborsRegressor
    from cuml.svm import SVR
    from cuml.ensemble import RandomForestRegressor as cuRF
    USE_GPU = True
    print(f"GPU detected — using cuML {cuml.__version__}")
except ImportError:
    from sklearn.linear_model import Ridge, Lasso, ElasticNet
    from sklearn.neighbors import KNeighborsRegressor
    from sklearn.svm import SVR
    from sklearn.ensemble import RandomForestRegressor
    USE_GPU = False
    print("No cuML — falling back to sklearn (CPU)")

# XGBoost: always installed, uses device="cuda" if GPU else "cpu"
xgb_device = "cuda" if USE_GPU else "cpu"
```
