## Context

The EDA covers 9 sections with 19 pre-rendered PNG figures and the underlying data/logic from the notebook. The Streamlit app will be **interactive** — computing plots on-the-fly from the dataset where possible (allowing filtering), and showing pre-rendered PNGs for expensive computations (t-SNE).

**Dependencies to install**: `streamlit`, `plotly` (for interactive scatter/3D plots)

---

## Implementation Steps

### Step 1: Install dependencies
```
pip install streamlit plotly
```

### Step 2: Create multi-page Streamlit app structure

```
streamlit_app/
├── app.py                    # Main entry point with sidebar navigation
├── pages/
│   ├── 1_Overview.py         # Dataset summary, key metrics
│   ├── 2_Bioactivity.py      # pchembl distribution, activity classes
│   ├── 3_Data_Quality.py     # Missing values, censored data, dedup
│   ├── 4_Temporal.py         # Publications over time, potency trends
│   ├── 5_Molecular_Properties.py  # Lipinski, descriptor histograms
│   ├── 6_Chemical_Space.py   # PCA/t-SNE (interactive plotly scatter)
│   ├── 7_Fingerprints.py     # Bit frequencies, sparsity, density comparison
│   ├── 8_Correlations.py     # Property-potency, top FP bits, heatmap
│   └── 9_QSAR_Readiness.py   # Summary assessment, recommendations
└── utils.py                  # Shared data loading, caching, helper functions
```

### Step 3: `utils.py` — shared utilities
- `@st.cache_data` to load the CSV once and share across pages
- Compute molecular descriptors (cached)
- Activity class assignment function
- Color palettes / constants

### Step 4: Each page
- **Page 1 (Overview)**: KPI cards (total records, unique mols, pchembl coverage, Lipinski %), dataset table preview, column descriptions
- **Page 2 (Bioactivity)**: Interactive histogram (adjustable bins, filter by standard_type), box plot, activity class pie chart with adjustable thresholds
- **Page 3 (Data Quality)**: Missing value bar chart, censored data breakdown, unit heterogeneity, deduplication stats
- **Page 4 (Temporal)**: Bar chart of records/year, violin by decade, cumulative discovery curve
- **Page 5 (Molecular Properties)**: Descriptor histograms with Ro5 lines, interactive scatter (choose X/Y axis from descriptors, color by activity), Lipinski compliance
- **Page 6 (Chemical Space)**: Interactive plotly scatter for PCA (color by activity or pchembl), pre-rendered t-SNE image (too slow to compute live), variance explained bar
- **Page 7 (Fingerprints)**: MACCS frequency bar, KR sparsity, density comparison, bits-per-molecule histogram — with dropdown to select FP type
- **Page 8 (Correlations)**: Property correlation bar chart, top FP bits bar chart, heatmap
- **Page 9 (QSAR Readiness)**: Text summary with key numbers, recommendations, class balance visualization

### Step 5: Run and verify
```
streamlit run streamlit_app/app.py
```
